# CAD and 3D-print files

## Biped add-ons

[`Biped/`](Biped/) contains the editable parametric TARS-style shells, rotating-neck support and simple grippers, the STL exports, print guide and export script. The 10 add-on STL meshes do not replace the vendor's lower-body frame; obtain that from the [official ROBOTIS MINI e-Manual](https://emanual.robotis.com/docs/en/edu/mini/).

## Stationary baseline

[`Stationary/`](Stationary/) contains the original fixed-support tabletop robot's OpenSCAD source, STL files, print guide and STL archive. These parts are separate from the biped add-ons.
